# 철권8 레이팅 획득 구조 조사 — 상하위 구간별 승/패 점수 비대칭 (2026-08-06)

`advice.ts`의 `noGainBands`("승률은 평균 이상인데 레이팅은 안 붙는 구간")를 설명하다가,
"이거 상위 구간에서 더 심한 거 아니야?"라는 질문에 실측(325명 표본)으로 답한 뒤 —
그 실측 결과가 게임 자체의 알려진 사양과 맞는지 인터넷 조사로 재확인했다.

> 후속: 이 문서가 인용한 "손익분기 1600대 52% → 2400+ 64%"(2026-08-05, 미문서화 조사)를
> 훨씬 큰 표본으로 재현·검증했다 — [rating-threshold-research.md](rating-threshold-research.md)
> (2026-08-07). `lib/tekken/quip-facts.ts`의 `DIVERGE_WIN_HI`/`LO` 고정값도 이 재검증
> 결과로 구간별 값으로 바뀌었다.

## 결론 먼저

- **승패 점수가 비대칭이라는 메커니즘 자체는 맞다.** 커뮤니티 실측 기준
  "같은 상대여도 이겨서 얻는 점수보다 져서 잃는 점수가 20~50 더 크다."
- **다만 "상위 구간이 더 심하다"는 예상은 반대에 가깝다.** 반다이남코가
  Ver.2.01에서 이 비대칭을 공식적으로 완화한 구간은 **Vanquisher~Battle Ruler**
  (하위~중위권)이었다 — 내 실측(레이팅 낮을수록 noGain 비율이 높았다, 이전 대화
  참조)과 방향이 일치한다.
- 이 사이트(및 wavu)가 쓰는 "레이팅"(glicko2, 1000~3000대)은 반다이남코의
  실제 "랭크 포인트"(0~999,999대, 단을 가르는 진짜 값)와 **다른 수치**다.
  메커니즘이 비슷한 이유는 두 시스템이 "레이팅 차이 → 기대 승률 → 점수 증감"이라는
  같은 원리(Elo/Glicko 계열)를 각자 쓰기 때문이지, 같은 값을 공유해서가 아니다.

## 1. 두 개의 서로 다른 숫자

| | 반다이남코 공식 "랭크 포인트" | wavu(이 사이트)의 "레이팅" |
|---|---|---|
| 스케일 | 0 ~ 999,999+ (연속값, 단의 경계) | 대략 1000~3000대 |
| 계산 주체 | 게임 서버 (비공개 로직) | wavu 커뮤니티 사이트 (glicko2 자체 계산) |
| 이 사이트에서 쓰는 값? | 아님 — wavu API가 안 준다 | 씀 (`myRating`/`myDelta`, `p1_rating_before` 등) |
| 예전 시도 | `docs/rank-point-attempt.md` — 단 전이 지점으로 역산 시도했다가 부정확해서 철회 | — |

`sessionAdvice()`의 `avgDelta`/`noGainBands`는 **wavu 레이팅** 기준이지 반다이남코
랭크 포인트 기준이 아니다. 아래 조사 내용은 "랭크 포인트" 쪽 공개 정보이고,
레이팅 쪽에 그대로 적용되는 숫자는 아니다 — 다만 **같은 부류의 시스템(상대 강함에
따라 기대값 대비 증감을 매기는 방식)**이라 방향성(비대칭이 왜 생기는가)은
참고할 만하다.

## 2. 반다이남코 랭크 포인트 — 알려진 사양

출처: 커뮤니티 위키·가이드 사이트 종합(정확한 공식은 비공개, 아래는 실측·역산 기반).

### 색 등급별 기본 구조

| 등급 | 특징 |
|---|---|
| 옐로 (초심자 랭크) | **패배해도 점수를 잃지 않는다.** 승리로만 오른다. |
| 오렌지 (Vanquisher~) | 승리 공식은 비슷하지만 **패배 시 점수 손실이 크게 늘어난다.** |
| 레드 | 같은 상대에게 3연승부터 승당 +400 보너스. |
| 퍼플 | 3연승부터 승당 +800 보너스, 3연패부터 패당 −400 페널티. |
| 블루 이상 | 승리 이득은 점점 줄고(diminishing), 패배 손실은 이득보다 커진다 — 연승이 핵심이 되는 구간. |

### 상대와의 랭크 차이에 따른 점수 (커뮤니티 실측, Steam 토론)

| 상대와의 차이 | 승리 시 | 패배 시 |
|---|---|---|
| −2단 (많이 낮음) | +200~250 | −250 |
| −1단 | +350~370 | −370~400 |
| 0 (동급) | +400 | −450 |
| +1단 | +500 | −550 |
| +2단 이상 | +500 (상한) | −550 |

> "같은 상대여도 이겨서 얻는 점수보다 져서 잃는 점수가 20~50 더 크다" — 이
> 비대칭은 등급을 막론하고 거의 항상 존재한다. 3연승/3연패 스트릭 보너스(±400~500)가
> 여기 얹힌다.

### 반다이남코의 자체 인정 — Ver.2.01 패치노트

공식 패치노트가 **랭크 포인트 비대칭 문제를 직접 언급**한다:

> "rank gaps created unfavorable asymmetry in scoring outcomes" — 랭크 격차가
> 점수 산정에 불리한 비대칭을 만들었다.

조치 내용:
- **Vanquisher ~ Battle Ruler 구간**(오렌지~퍼플, 즉 하위~중위권)에서 **패배 시
  점수 손실을 줄임**.
- 낮은 랭크 상대를 이겼을 때 얻는 점수를 늘리고, 그 상대에게 졌을 때 잃는 점수를 줄임.
- Tekken God 미만 전 구간에 걸쳐 변동폭·강등 방지 로직도 조정.
- 배경: "시즌 2에서 오히려 랭크 올리기가 시즌 1보다 어려워졌다"는 피드백.

**즉, 반다이남코 스스로도 "약한 상대를 이겨 봐야 조금 벌고 강한 상대(또는 이변으로
약한 상대)에게 지면 크게 잃는" 비대칭을 인지했고, 그게 가장 심했던 구간이
하위~중위권(Vanquisher~Battle Ruler)이었다** — 최상위가 아니라.

## 3. 이 사이트의 실측(2026-08-06, 이전 대화)과의 대조

WPF 캐시(325명, wavu 레이팅 기준)로 직접 돌려본 결과:

| 최종 레이팅 | noGain 비율 |
|---|---|
| ~1500 | 91.0% |
| 1500~1800 | 82.4% |
| 1800~2100 | 79.8% |
| 2100~2400 | 57.9% |
| 2400~ | 0% (표본 1명, 신뢰 안 됨) |

레이팅이 낮을수록 noGain(승률은 좋은데 레이팅이 안 붙는 구간)이 더 흔했고,
noGain 안에서 승리 시 평균 +11.05점, 패배 시 평균 −14.67점(패배가 1.33배 더 아픔)이었다.

이건 반다이남코가 **랭크 포인트에서 공식적으로 인정하고 고친 구간**(Vanquisher~
Battle Ruler, 하위~중위권)과 방향이 정확히 겹친다. 두 시스템(랭크 포인트 vs wavu
레이팅)이 다른 숫자이긴 하지만, **"매칭 폭이 넓어 약한 상대를 자주 만나는 구간일수록
이 비대칭이 커진다"**는 같은 구조적 이유로 설명된다 — 하위~중위권은 인구가 많고
매칭 스킬 폭이 넓어 약한 상대와 자주 붙고, 최상위(God of Destruction 근처)는
인구가 얇아 상대적으로 비슷한 실력끼리만 매칭되는 경향이 있다(이 마지막 문장은
사양 확인이 아니라 흔한 설명이다 — 검증되지 않은 추정으로 남겨둔다).

## 4. 화면 문구에 남길 것 / 확인 필요

- `adviceNoGain` 문구("승률만 보면 안 보이는 구간")는 그대로 유효하다 — 근거가
  더 탄탄해졌을 뿐 바뀔 내용은 없다.
- "레이팅이 낮을수록 이 현상이 흔하다"는 실측 결과를 화면 문구에 넣을지는 별개
  판단이다 — 표본 325명(그마저 최상위 구간 1명)이라 사이트 전체 통계로 내세우기엔
  약하다. 넣는다면 "이 사이트가 지금까지 본 표본에서는"이라는 단서가 필요하다.
- 반다이남코 공식 확률/점수 공식은 **비공개**다. 위 표는 전부 커뮤니티 역산치이고
  버전마다(특히 Ver.2.01 전후로) 바뀌었을 수 있다 — 원문 링크를 항상 같이 밝힐 것.
