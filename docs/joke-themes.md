# 농담 소재 후보 — 무엇을 넣고 무엇을 빼는가

`app/jokes.ts` 에 더 넣을 만한 은유 소재를 평가하고 순서를 정한다.

상태: **미적용** (2026-08-03 분석)

관련 문서: [advice-text.md](advice-text.md) · [mood-baseline.md](mood-baseline.md)

---

## 0. 판정 기준 — 소재는 두 범주다

섞어 재면 안 된다. 판정 기준이 서로 다르다.

### (A) 구조 은유 — 등산·요리·요요·주식·연애

**승부 구조와 대응이 되는가.**

기존 소재(로또·주식·연애·직장)가 잘 먹히는 건 웃겨서가 아니라
**"노력 대비 결과가 배신한다"** 는 구조가 승률과 같아서다.
구조가 안 맞으면 문장이 농담이 아니라 그냥 딴소리가 된다.

### (B) 시선 소재 — 프로·방송

**"제3자가 이걸 본다면"** 이라는 설정을 빌린다. 구조 대응이 아니라 **관점 이동**이다.
이미 `app/jokes.ts` 의 프로 소재가 이 범주고(감독·스폰서·중계·해설자·다시보기),
톤 규칙도 거기서 나왔다. 판정 기준이 둘 있다:

1. **가정이 문장 안에 있는가** — 조회하는 사람에겐 감독도 구독자도 없다.
   단정형은 문장이 붕 뜨거나 진짜 현실 얘기로 읽힌다.
   (사고 이력은 `app/jokes.ts` 머리말 참조)
2. **대상이 '오늘의 성적'인가 '사람'인가** — 시선 소재는 이 선을 넘기가 제일 쉽다.
   제3자를 등장시키는 순간 "그 사람이 당신을 비웃는다"로 미끄러진다.

### 두 범주 공통 부차 기준

- **한국어 관용구가 붙는가** — 원문이 한국어라 여기서 밀도가 갈린다.
- **`COACH` 에도 붙는가** — 조언 배열은 리플레이·확정딜캐·유튜브 세 표현만
  돌려 써서 **반복이 제일 심한 곳**이다. 여기까지 닿는 소재는 값이 두 배다.

## 1. 요청받은 넷

| 소재 | 판정 | 한 줄 이유 |
|---|---|---|
| 등산 | **◎** | 레이팅·단 구조와 1:1 대응. 은유가 아니라 거의 번역이다 |
| 요리 | **○** | 과정-결과 구조가 같고, 유일하게 `COACH` 까지 닿는다 |
| 바다 | **△** | 구조가 헐겁고 안전선과 인접. 좁게만 |
| 산 | — | 등산에 흡수된다. 따로 둘 이유 없음 |

### 등산 ◎ — 넷 중 최우선

| 등산 | 대응 |
|---|---|
| 8부 능선 | 승급 직전 |
| **하산할 때 사고가 난다** | **승급 직후 연패** |
| 고도만 보고 걷기 | 레이팅만 보기 |
| 산은 도망가지 않는다 | 기존 cold 의 `철권은 도망가지 않습니다` 와 같은 계열 |

```
hot      오르막에서 숨이 안 차는 날입니다. 이런 날은 정상까지 가는 겁니다.
steady   능선입니다. 오르막도 내리막도 아닌 구간이 제일 깁니다.
cooling  여기서 무리하면 하산이 위험해집니다.
cold     사고는 오를 때가 아니라 내려올 때 납니다. 오늘은 내려오세요.
```

**하산 사고 = 승급 후 연패**는 [advice-text.md](advice-text.md) 와 별개로 앞서 정리한
**승단·강등 축**과 소재가 맞물린다. 그 축을 붙일 때 문구를 재활용할 수 있다.

### 요리 ○ — 유일하게 `COACH` 까지 닿는다

과정-결과 구조가 승부와 같고(재료·불조절·타이밍·간), 실패가 일상적이라 자조하기 쉽다.
한국어 관용구가 풍부하다 — 설익다, 뜸 들이다, 손맛, 간을 보다.

**레시피 = 확정딜캐** 대응이 자연스러워서 농담뿐 아니라 `COACH` 배열에도 들어간다.

```
hot      오늘은 간이 딱 맞습니다. 레시피를 적어두세요.
steady   늘 같은 맛입니다. 나쁘지 않은데 새로울 것도 없죠.
cooling  불이 세졌습니다. 조금 줄이세요.
cold     오늘은 태웠습니다. 다음 판을 올리기 전에 팬부터 식히시죠.
COACH    레시피를 다시 보고 오세요. 확정딜캐가 그 레시피입니다.
```

기존 음식 소재(한강 라면·삼계탕·붕어빵)와도 이어진다.

### 바다 △ — 좁게, 그리고 선을 명시할 것

등산만큼 구조가 안 맞고 **이미 그어둔 안전선과 인접하다.**
`app/jokes.ts` cold 주석에 이렇게 적혀 있다:

> 한강 — '나가라' 계열의 연장. 라면·치킨·자전거 쪽이고, **수온 밈은 쓰지 않는다.**

바다는 익사·조난 쪽으로 미끄러지기가 한강보다 쉽다.
쓸 수 있는 범위는 좁다 — 파도·조류·잔잔함/풍랑, 그리고 낚시(이미
`낚시 게임을 추천합니다` 가 있다). 여름 계절 pool 과도 소재가 겹친다.

**넣는다면 8줄 이내로 파도·낚시에 한정하고, 물에 빠지는 계열은 주석에 금지로 명시할 것.**

```
steady   잔잔합니다. 뱃사람은 이런 날을 제일 좋아합니다.
cooling  조류가 바뀌었습니다. 거스르면 체력만 나갑니다.
```

## 1-B. 방송·유튜브 ◎ — 시선 소재 (B범주)

> "코미디 프로를 볼 필요가 없다, 네 게임 보는 게 웃기다"
> "유튜브 채널 개설할 생각 없냐, 코미디 채널로 먹고살겠다"
> "사건사고 채널 컨셉이냐"

프로 소재의 **자매 소재**다. 프로가 "직업이었다면 방출"이라면 이건
"콘텐츠였다면 예능"이다. 같은 관점 이동(제3자가 본다)의 다른 장르.

화력이 셋 중 제일 좋다. 특히 `cold` 에서 강하고, 의외로 `steady` 에서도 성립한다
("편집할 게 없는 하루").

### 프로 소재와의 경계 — 지켜야 중복이 안 난다

기존 프로 소재가 **스포츠 중계**를 이미 가져갔다:

```
app/jokes.ts:176   해설자가 있었으면 목소리가 커졌을 구간입니다.        (hot)
app/jokes.ts:1103  중계가 붙었다면 해설자가 할 말을 잃었을 겁니다.       (cold)
app/jokes.ts:1107  중계가 있었다면 오늘 경기는 다시보기에서 내렸을 겁니다. (cold)
```

→ **방송 소재는 유튜브·예능 쪽만 쓴다.** 해설자·중계·다시보기는 건드리지 않는다.
남는 어휘가 충분하다: 채널·구독자·조회수·댓글·썸네일·편집점·통편집·
사건사고·블랙박스·제보·모자이크·짤.

`hot` 에서 하나 더 조심할 것 — 이미 이런 줄이 있다:

```
app/jokes.ts:128   이 승률이면 코칭 영상을 찍어도 되겠습니다. 조회수는 별개고요.
```

"강의 영상 찍어라"는 선점됐다. 방송 소재의 `hot` 은 **하이라이트·편집** 쪽으로 간다.

`COACH` 는 유튜브를 **"보러 가라"** 로 쓰고 있어서(매치업 영상·콤보 영상) 방향이
반대다. 충돌하지 않는다.

### 예시

```
hot      오늘 판은 편집 없이 그대로 올려도 됩니다.
         썸네일에 쓸 장면이 오늘만 여럿 나왔습니다.
         채널이 있었다면 오늘이 개국 첫 방송으로 딱입니다.

steady   편집할 구간이 없습니다. 통편집이 정답입니다.
         썸네일로 쓸 장면이 없습니다. 그만큼 무사했다는 뜻이죠.
         브이로그라면 몰라도 하이라이트로는 안 됩니다.

cooling  슬슬 편집점이 생기기 시작했습니다. 좋은 쪽은 아니고요.
         지금부터는 게임 채널이 아니라 예능 쪽 소재가 됩니다.

cold     코미디 프로를 볼 필요가 없습니다. 오늘 판이 그 자리를 대신합니다.
         유튜브를 하셨다면 예능 채널로 자리를 잡으셨을 겁니다.
         이건 게임 채널이 아니라 사건사고 채널 소재입니다.
         오늘 경기에는 모자이크가 필요합니다.
         편집자가 있었다면 오늘 분량은 통째로 들어냈을 겁니다.
         구독자가 있었다면 오늘로 몇 명 빠졌을 겁니다.
         웃기려고 한 게 아닌데 웃깁니다. 그게 제일 강력한 코미디죠.
```

### 이 소재에서 특히 조심할 것

0장 (B)의 두 번째 기준 — **대상이 '오늘의 성적'인가 '사람'인가** — 이 소재가
그 선을 제일 쉽게 넘는다. 원안의 "네 게임 보는 게 웃기다"를 그대로 옮기면
**사람을 웃음거리로 만드는 문장**이 된다.

| 안 됨 | 됨 |
|---|---|
| 당신 플레이를 보면 웃깁니다 | 오늘 판이 코미디 프로 자리를 대신합니다 |
| 당신은 코미디 채널이 어울립니다 | 유튜브를 하셨다면 예능 채널로 자리를 잡으셨을 겁니다 |

주어를 **사람이 아니라 오늘의 경기**로 두면 같은 농담이 성립한다.
`웃기려고 한 게 아닌데 웃깁니다` 처럼 **주어를 아예 지우는 것**도 안전한 형태다.

가정법은 프로 소재보다 느슨해도 된다. 감독·스폰서와 달리 **유튜브는 실제로
누구나 할 수 있어서** "채널을 여셨다면"이 억지가 아니고, "지금 켜세요"도 성립한다.
다만 `cold` 에서는 가정을 붙이는 쪽이 순하다.

## 2. 추가 추천 셋

### ① 다이어트·요요 ◎ — 은유 정확도가 제일 높다

**요요 = 승률 원상복귀.** 기존 cold 의 운동 소재와도 이어진다.

```
한 달 올린 레이팅이 하루에 돌아갔습니다. 요요가 원래 그렇습니다.
쉬운 상대로 올린 레이팅은 근육이 아니라 수분입니다.
```

### ② 공부·시험 ○ — `COACH` 반복 해소

**오답노트 = 리플레이** 대응이 조언 배열과 직결된다.

```
틀린 문제를 안 보면 다음에도 틀립니다. 오답노트 쓰세요.
벼락치기로 오른 레이팅은 벼락치기로 내려갑니다.
```

### ③ 운전 △

이미 씨앗이 하나 있다 — cooling 의 `내리막길에서 브레이크는 밟으라고 달려 있는 겁니다`.
초보운전·정체·과속으로 늘릴 수 있지만 앞의 둘만큼 구조가 안 맞는다.

### 검토했다가 뺀 것

| 소재 | 뺀 이유 |
|---|---|
| 농사 | 계절 pool 과 겹친다. 이미 `농사짓는 게임을 켜세요` 로 한 번 쓰였다 |
| 날씨 | 계절 축에 흡수된다 |
| 출퇴근·교통 | 시각 축(`fact-jokes`)과 겹친다 |
| 육아 | 개인 사정 편차가 너무 크다. 톤 규칙의 '실제로 힘든 주제'에 닿는다 |

## 3. 구조 — 전부 '축'이 아니라 '소재'다

계절(`season-jokes.ts`)이나 데이터 인용(`fact-jokes.ts`)과 달리 **여는 조건이 없다.**
언제 나와도 성립한다.

→ **새 파일도, 게이트도, 우선순위 조정도 필요 없다.**
프로 소재와 똑같이 기존 `JOKES` pool 에 주석 블록으로 넣으면 끝이다.
확률 배분(`SEASON_EVERY`, `fact-jokes` 의 사건/특성 우선순위)을 안 건드리는 게 큰 장점이다.

### 지켜야 할 것 둘

1. **소재별 주석 블록을 유지할 것.**
   프로 소재는 `// 프로 —` 주석으로 묶여 있어서 세고 검사할 수 있었다.
   태그 없이 섞어 넣기 시작하면 "요리 소재가 몇 개인지", "세 언어 균형이 맞는지"를
   확인할 방법이 사라진다. 검사 스크립트를 붙일 수 있는 유일한 근거다.

2. **소재 하나당 최소 8~10줄.**
   현재 풀이 hot 95 / steady 87 / cooling 92 / cold 154 다.
   5줄짜리 소재는 사실상 화면에 안 나온다.

## 4. 순서

| | 소재 | 범주 | 이유 | 분량 (언어당) |
|---|---|---|---|---|
| 1 | **방송·유튜브** | B | 화력 최고. 프로 소재 톤이 이미 검증돼 재사용 | 14 |
| 2 | 등산 | A | 승급·강등 축과 맞물림 | 12 |
| 3 | 요리 | A | 농담 + `COACH` 양쪽 | 12 + COACH 4 |
| 4 | 다이어트·요요 | A | 은유 정확도 최고 | 10 |
| 5 | 공부·시험 | A | `COACH` 반복 해소 | 10 |
| 6 | 바다 | A | 좁게, 안전선 주석 필수 | 8 |
| — | 운전 | A | 여력 있으면 | 8 |

방송을 1번에 둔 이유: **프로 소재의 톤 규칙(가정법·대상 제한)이 그대로 적용돼서**
새로 판단할 게 없다. 어휘 경계(중계·해설자 제외)만 지키면 된다.

세 언어 분량을 맞추므로 1~6 전부 넣으면 **약 (14+12+12+10+10+8) × 3 = 198줄**,
`COACH` 4 × 3 = 12줄이 는다.

## 5. 넣을 때 같이 할 것

- 세 언어 분량 일치 확인 (현행 정책: 번역이 아니라 **같은 성격의 다른 문장**으로 채운다)
- `npm run check` 통과 — 소재 블록을 세는 검사를 붙일지는 3장 1번 규칙에 달렸다
- 바다를 넣는다면 cold 주석의 한강 규칙 옆에 **물에 빠지는 계열 금지**를 나란히 적을 것
- 방송을 넣는다면 소재 주석에 **어휘 경계**를 적을 것 —
  "중계·해설자·다시보기는 프로 소재가 이미 쓴다. 여기는 유튜브·예능 쪽만."
  경계를 안 적으면 다음 사람이 `해설자가 할 말을 잃었습니다` 를 또 쓴다
  (실제로 프로 소재를 넣을 때 그 문장이 두 번 나올 뻔했다)
